# 복지제도 찾기

대상자의 나이대·가구 상황·지역을 고르면 복지로에 올라 있는 중앙부처·지자체 복지제도 가운데 살펴볼 만한 것을 모아 보여 주는 화면입니다.
사회복지·자활 현장 실무자의 상담 준비를 돕는 참고용 도구이고, **복지로의 공식 서비스가 아닙니다.** 받을 수 있는지 판정하지 않습니다.

- 주소: https://jahwalktg.github.io/bokjiro-search/
- 자료: 복지로(한국사회보장정보원)의 「중앙부처복지서비스」·「지자체복지서비스」 공개 자료(공공데이터포털, 이용허락범위 제한 없음)를 미리 받아 `data/`에 둡니다. 화면 맨 위와 제도마다 받은 날짜가 적혀 있습니다.
- `data/`는 스크립트가 만드는 파일입니다. 직접 고치지 않습니다.
- 고른 조건과 메모는 저장하지 않고 어디에도 보내지 않습니다.
- 만든 사람: 서울강남지역자활센터 김태균
